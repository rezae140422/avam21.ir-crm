# Avam21.ir — CRM

**Built by Hamidreza Lotfi — 2026**

## Overview

A CRM system for a financial-services business, intended to help organise client relationships and follow up requests and services in a structured way.

## General scenario

- Managing customer records and communication history at a general level
- Tracking requests, tasks and follow-ups for a small team
- Role-based access for staff and a general overview of activity
- A secure-by-design internal web interface, described only in general terms

This page is a general, anonymous summary only. Client data, business details, and confidential information are not included on this page.

## Why the code is not published

The delivered code belongs to the client and is confidential. Publication or reuse of that code is prohibited. The code is kept only in a private internal archive, recorded with a SHA-256 hash for integrity (the hash itself is not published here).
